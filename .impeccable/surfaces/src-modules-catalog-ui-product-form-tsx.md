# Brand product editor

- Scope: the shared brand Add product and Edit product form. Mode: Operate. This records the implemented extension of the established Xurjin visual world; it does not replace global DESIGN.md or its sidecar. Shared product details have small previous/next gallery arrows when more than one image exists and an owner-only Edit product action.
- Saved-product navigation: View product in the editor heading opens the same product ID at the shared details route and honors unsaved-change protection. The brand catalogue photo/title opens that shared route; its owner-only Edit product action returns to this editor. Archived details remain visible only to the approved owning brand, with an explicit archived notice. Desktop and mobile brand return controls lead to the brand catalogue. These controls retain the established white/bordered and cobalt action styles and wrap for Georgian on narrow screens.
- Audience and job: brands prepare product details, order product photography, set a creator commission offer and affiliate terms, inspect unsaved values in a creator preview, and explicitly publish or save. Creator and link management stays in the separate Creators & links destination for saved products.
- Authority: `C:/Users/mefar/Downloads/Xurjin-Product-Editor-Guide.md` and `01-add-product-desktop-mobile.png` / `02-edit-offer-terms-desktop-mobile.png` under `C:/Users/mefar/Downloads/Xurjin-Product-Editor-Handoff/Xurjin-Product-Editor-Handoff/references`. The guide governs differences from illustrative boards, including optional description, mobile section navigation and truthful commission labels. Sample photography, products, amounts and dates are not defaults or product facts.
- Direction and visual contract: preserve navy workspace navigation, pale canvas, white bordered cards, cobalt actions, shared bilingual sans typography and numbered terms disclosures. The heading is 29px on desktop and 24px on mobile; ordinary text is 14–16px. Cards use 12px corners, controls generally use 7px corners and a 44px minimum height. Existing money formatting and icons carry into the editor. Worded states accompany status colour.
- Desktop composition: Products breadcrumb and Add/Edit heading precede three anchors: Product details, Commission offer and Affiliate terms. Edit includes saved product identity, lifecycle status and overflow actions. One continuous form uses a flexible field column beside a 320px creator preview with a 24px gap, inside a page capped at 1340px. The preview sticks 96px from the top and scrolls within the available viewport. At 1199px and below, the layout becomes one column and the sidebar preview hides. Anchors scroll to sections and retain values; this is not a staged wizard.
- Mobile composition: at 760px and below, both locales and both modes use 16px page gutters, stacked fields, 16px input text and a Jump to section select. The fixed bottom action bar wraps its worded state above Preview and the primary action, includes safe-area padding, and has reserved page space beneath the form. The workspace bottom navigation and footer hide on this focused surface. Preview opens a full-screen native dialog with Back to editing; closing it retains values and editing position. Georgian labels and long values wrap within the same hierarchy.
- Field contract: Product details contains product name, SKU, product type, optional description, GEL price, Product page URL and images. Commission offer contains percentage/fixed GEL selection, its value and Attribution window in days. Visible labels replace Backlink URL and cookie window while preserving API field names. Switching commission type clears the amount so a percentage is not silently reinterpreted as GEL. Required markers and limits follow the shared input schema; description remains optional.
- Terms contract: three numbered groups retain every existing term field. Payout & attribution contains payout timing and optional offer start/end. Promotion & channels contains allowed channels, prohibited promotion methods, content/approval requirements and coupon policy. Regions & other conditions contains ISO country codes, returns/cancellations and special conditions. Expandable selectors retain all channel/restriction options and saved selections. Empty regions and empty restriction selections retain their unrestricted meaning. Collapsing a group does not discard its values.
- Image contract: a compact thumbnail grid and Add images tile support up to eight JPG, PNG or WebP files, 5 MB each. The first image is primary; a visible badge, Set as primary, move controls and drag-and-drop expose ordering. Keyboard-accessible per-image actions remain available. Upload progress, retry and removal of a failed upload are explicit; completed uploads and other form values survive a later upload failure. Saving is blocked during uploads and while a failed upload remains unresolved. Image removal changes the unsaved list; existing images are not permanently deleted before successful Save.
- Creation and ownership: Add reserves a signed, owner-scoped upload namespace before creating a product. Reservation alone neither persists nor publishes a product. Presign and create verify ownership; uploaded objects are verified before acceptance. Edit loads and mutates only the current brand's product. Successful creation replaces the Add URL with the saved editor destination, so refreshing does not repeat creation.
- Preview contract: Creator view · Preview reflects unsaved product name, brand, primary image only, estimated creator commission, price, offered attribution window, description and a terms summary. It reuses the product image presentation and currency formatter. The canonical commission helper calculates fixed or percentage earnings; blank or invalid input shows a placeholder. Preview creates neither a product nor a tracking link and invents no eligibility, payout status or public URL. The editable thumbnail gallery remains the place to inspect and reorder all images.
- Offer and historical truth: saving changed offer/terms creates a new version for new link acceptances. Existing tracking links retain their accepted rate and terms snapshots, and recorded conversions are not recalculated. The editor explains this near the offer. A non-30-day offered attribution value is stored, but conversion attribution currently enforces 30 days regardless of that value; both the field and preview disclose the distinction. This redesign does not change attribution or commission calculation behavior.
- Save and validation: one persistent action bar shows Not published with Publish product in Add, Unsaved changes with Save changes for dirty Edit, and All changes saved with disabled Save changes for unchanged Edit. Saving feedback and submission guards prevent duplicate mutations. Shared validation and native constraints produce inline field errors, open the containing disclosures and focus the first invalid field. URL, date ordering, region codes, prices and rates are checked; duplicate SKU is attached to SKU. Server errors retain entered values and receive a focused alert. The saved state updates only after server confirmation; no autosave or draft persistence is implied.
- Unsaved navigation: dirty state includes fields, selections and image order/removal. A same-URL history sentinel catches browser Back before route navigation, including browsers without the Navigation API. Declining discard restores the editor history position; accepting leaves. Link navigation, workspace navigation and page unload also guard unsaved changes, and navigation is blocked during saving. Back closes an open preview before asking to leave the dirty editor. Returning to the saved baseline removes the sentinel.
- Archive lifecycle: Edit overflow exposes Archive only for an active saved product and uses a scoped confirmation. It explains that the product becomes unavailable to creators, links stop accepting new clicks, existing click attribution and conversion history remain intact, and unsaved edits will be discarded. Archive success returns to the product catalogue. Creators & links remains separate and receives the same unsaved navigation protection.
